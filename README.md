# TenderAI
AI-powered Tender Management &amp; Vendor Evaluation System built with Flask, MongoDB, and Groq AI (LLaMA). Features vendor ranking, tier-based allocation, bid analysis and PDF report generation.
🏗️ TenderAI — Intelligent Tender Management System

A full-stack web application for Tamil Nadu government tender 
management and vendor evaluation using AI.

🔧 Tech Stack:
- Python & Flask (Backend)
- MongoDB (Database)
- HTML/CSS (Frontend)
- Groq AI / LLaMA (AI Analysis)
- ReportLab (PDF Generation)

✨ Features:
- Admin & Vendor login system
- Create and manage 1000+ vendors
- Post tender projects with deadlines
- AI-powered vendor scoring & ranking
- Tier-based fair vendor allocation (A/B/C)
- Bid anomaly detection using AI
- Project risk assessment using AI
- PDF report generation with charts
- 525 Tamil Nadu tenders database
- Auto-responder for testing
